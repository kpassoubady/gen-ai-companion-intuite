# Afternoon Session: RAG Chatbot and API

Welcome to the Day 3 Afternoon Session!

## Objective
1. **Lab 3.2: End-to-End RAG Chatbot** - Build a complete Retrieval-Augmented Generation system that answers questions about a local markdown knowledge base.
2. **Lab 3.3: Flask API for the RAG Chatbot** - Expose the RAG system built in Lab 3.2 via a REST API using Flask.

## Setup
Before you begin, make sure you have activated your Python virtual environment. If you haven't set up the environment yet, please follow the [Setup Instructions](../../../README.md) in the root of the repository.

## Instructions

We have provided boilerplate code in the `start/` directory. Your goal is to complete the `TODO` sections in each file.

### Lab 3.2: End-to-End RAG Chatbot (`lab3_2_rag_chatbot.py`)
Build a complete RAG system that answers questions about a knowledge base.
1. Navigate to the `start/` folder and open `lab3_2_rag_chatbot.py`.
2. Complete the `TODO` sections to:
   - Load markdown documents from `day3/afternoon-labs/knowledge-base/`.
   - Chunk the documents while preserving source metadata.
   - Embed chunks using `litellm` and store them in a FAISS index.
   - Build a query loop: user asks a question, system retrieves relevant chunks, and generates an answer.
   - Cite sources in every answer generated by the LLM.
3. **Stretch goals:**
   - Experiment with `chunk_size` (200, 500, 1000) — compare retrieval quality.
   - Add a relevance threshold — don't use chunks below a certain similarity score.
   - Combine RAG with conversation history for multi-turn RAG.
4. Run the file: `python lab3_2_rag_chatbot.py`

**Expected interaction:**
```text
🔍 RAG Chatbot — Lab 3.2
Loading knowledge base...

📄 Loaded 5 documents
✂️  Created 18 chunks
🔢 Embedding chunks...
🗄️  FAISS index ready: 18 vectors

👤 You: What is a Python dictionary?

🤖 Bot: A dictionary in Python is a data structure that stores key-value pairs with O(1) average lookup time...
📚 Sources: python-data-structures.md
```

### Lab 3.3: Flask API for the RAG Chatbot (`lab3_3_flask_api.py`)
Wrap the RAG chatbot from Lab 3.2 in a Flask API.
1. Open `lab3_3_flask_api.py` in the `start/` folder.
2. Complete the `TODO` sections to:
   - Copy over your working RAG implementations (loading, chunking, embedding, indexing, retrieval) from Lab 3.2.
   - Implement the health check endpoint at `GET /api/health` returning `{"status": "ok", "chunks_loaded": N}`.
   - Implement the chat endpoint at `POST /api/chat` that accepts `{"message": "..."}` and returns `{"answer": "...", "sources": [...]}`.
3. **Stretch goals:**
   - Add session-based conversation history.
   - Add response caching for repeated queries.
   - Add a `GET /api/sources` endpoint listing all indexed documents.
4. Run the file: `python lab3_3_flask_api.py`
5. **Test with `curl`:**
   ```bash
   curl -X POST http://localhost:5001/api/chat \
     -H "Content-Type: application/json" \
     -d '{"message": "What Python data structures are used for key-value pairs?"}'
   ```
