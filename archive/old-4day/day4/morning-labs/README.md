# Morning Session: Productionizing LLMs (Moderation, Caching, Evals)

## Objectives
1. Add input filtering, PII redaction, and output filtering to the chatbot.
2. Implement response caching and token counting for cost measurement.
3. Build an evaluation harness to run test prompts and score responses.

## Setup
Before starting, ensure your Python environment is activated and you have set up your API keys.
Please see the [Setup Instructions](../../README.md) at the root of the repository.

## Instructions
1. Open the `start/` directory.
2. Follow the `TODO` comments in each lab file.
3. Run each lab to test your implementation:
   ```bash
   cd start
   python lab4_1_moderation_layer.py
   python lab4_2_caching_cost.py
   ```

## Getting Stuck?
If you get stuck, you can refer to the fully implemented code in the `solution/` directory.
