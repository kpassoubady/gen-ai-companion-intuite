In Python, errors are typically referred to as exceptions. Exceptions are events that occur during the execution of a program that disrupt the normal flow of the program's instructions. When an error occurs, Python raises an exception, which can be handled using a try-except block. If the exception is not handled, it will terminate the program and display an error message, often referred to as a traceback.

Here are some common types of exceptions in Python:

1. **SyntaxError**: This occurs when the parser encounters a syntax error. For example, a missing colon at the end of a function definition will raise a SyntaxError.

2. **IndentationError**: This is a subclass of SyntaxError and occurs when there is an incorrect indentation. Python relies on indentation to define the structure of the code.

3. **TypeError**: This occurs when an operation or function is applied to an object of inappropriate type. For example, trying to add a string and an integer will raise a TypeError.

4. **NameError**: This occurs when a local or global name is not found. For example, trying to access a variable that has not been defined will raise a NameError.

5. **IndexError**: This occurs when trying to access an index that is out of range for a sequence, such as a list or a tuple.

6. **KeyError**: This occurs when trying to access a dictionary with a key that does not exist.

7. **ValueError**: This occurs when a function receives an argument of the right type but an inappropriate value. For example, trying to convert a non-numeric string to an integer will raise a ValueError.

8. **AttributeError**: This occurs when an invalid attribute reference or assignment is made. For example, trying to access a method or property that does not exist on an object will raise an AttributeError.

9. **ImportError**: This occurs when an import statement fails to find the module definition or when a from ... import fails to find a name that is to be imported.

10. **ZeroDivisionError**: This occurs when a division or modulo operation is performed with zero as the divisor.

11. **FileNotFoundError**: This occurs when trying to open a file that does not exist.

To handle exceptions in Python, you can use a try-except block:

```python
try:
    # Code that may raise an exception
    result = 10 / 0
except ZeroDivisionError as e:
    # Code to handle the exception
    print("Cannot divide by zero:", e)
```

In this example, the ZeroDivisionError is caught, and the program prints a message instead of terminating unexpectedly.

Python also allows you to define your own exceptions by creating a new class that inherits from the built-in `Exception` class. This can be useful for creating specific error types for your application logic.

   - **Example**:
     ```python

     print("Hello")
     ```
     *Fix*: Indent the `print` statement to be part of the function block:
     ```python
     def my_function():
         print("Hello")
     ```

   - **Example**:

     ```python
     value = 10
     ```
