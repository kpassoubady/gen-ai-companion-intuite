# Lab 1.1 - Train and Evaluate a Classifier

**Day 1 - Session 1** (optional lab)

## Objectives

1. Split a small tabular dataset into training and test sets.
2. Train a classifier with scikit-learn.
3. Evaluate it with accuracy, precision, recall, and F1.
4. See overfitting by comparing train and test scores.

## Setup

Run in Google Colab (recommended): open `start/lab1_1_classifier.ipynb` with the
"Open in Colab" badge and run the first cell to install dependencies.

To run locally instead, activate the repo virtual environment and install
requirements. See the [root README](../../README.md).

## Instructions

1. Open `start/lab1_1_classifier.ipynb`.
2. Find each `# TODO` marker and fill it in, top to bottom.
3. Run every cell. You should reach about 0.97-0.99 accuracy with logistic
   regression, and see a clear train-test gap for the deep decision tree.
4. Try the stretch goals at the end if you finish early.
