# Day 1 Labs - Foundations of AI/ML & Generative Architectures

Hands-on labs for Day 1. Each lab has a `start/` notebook with `# TODO` markers
and a `solution/` notebook with the full working code. Every lab runs on a Google
Colab CPU runtime with no GPU required.

| Lab | Topic | Session |
| :--- | :--- | :--- |
| [Lab 1.1](lab1_1_classifier/) | Train and evaluate a classifier (optional) | Session 1 |
| [Lab 1.2](lab1_2_image_clf/) | Image classification with PyTorch | Session 2 |
| [Lab 1.3](lab1_3_vae/) | Generate handwritten digits with a VAE | Session 3 |
| [Lab 1.4](lab1_4_diffusion/) | Generate images with a diffusion pipeline | Session 4 |

## How to run

Open a lab's `start/` notebook with its "Open in Colab" badge and run the first
cell to install that lab's dependencies. Work through the `# TODO` markers. The
matching `solution/` notebook has the reference answer.

To run locally instead, see the [root README](../README.md) for environment
setup.
